Pendencias Tecnicas
Pontos fixos para avaliacao futura do Hub.
⚠️ Ponto 1 - Sincronizacao de dados:
Os dados estao armazenados localmente (LocalStorage). Colaboradores acessando de dispositivos diferentes nao sincronizam automaticamente. Solucao futura: migrar para Supabase.
⚠️ Ponto 2 - API de IA:
Atualmente usando Groq (llama-3.3-70b-versatile) para M9 e M12. Avaliar futuramente a migracao para API da OpenAI com conta propria da empresa dependendo de custo e volume de uso.
⚠️ Ponto 3 - Refatoracao DRY:
Ao final do desenvolvimento completo, rodar o seguinte prompt no Claude Code: "Identifique padroes de codigo duplicados no projeto. Procure por funcoes, componentes ou blocos de codigo que aparecem em varios lugares com pouca ou nenhuma alteracao. Sugira refatoracoes para criar componentes reutilizaveis, hooks personalizados que possam substituir essa duplicacao, seguindo o principio DRY (Don't Repeat Yourself)."
